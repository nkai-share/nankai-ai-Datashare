## 1. 项目性质
本项目是一项**无偿**的资料整理与分享活动，致力于实现学习资料的跨年级高效传播，构建可持续的校园学术传承生态。

## 2. 项目目的
* **消除信息差**：打破复习资料的获取壁垒，让大多数同学能够公平、轻松地获取往年复习参考资料。
* **减负增效**：减少在无意义重复劳动上花费的时间。
* **助力成长**：鼓励同学们将节省下来的精力，投入到对自身长远发展更有利的科研、社团或个人能力提升活动中去。

## 3. 核心准则
在获取资料前，请确保您认同以下原则：
* **无偿分享**：所有资料均由学长学姐无偿整理，并经过了一定的审核与补充。
* **严禁商业化**：资料仅用于复习与交流，**严禁任何形式的商业买卖行为**。

## 4. 加入我们
项目采用动态更新和实时调整机制，每年都需要新鲜血液的加入。如果您具备以下能力之一，欢迎联系我们：
* **资料收集与整理能力**：擅长整理复习资料、ppt、回忆版试题、往年真题等。
* **推广能力**：负责项目的社群宣传，提升覆盖面。
* **项目管理能力**：协调内部分工，把控项目进度。

> **我们希望您也是一个具有开源精神的分享者。** 加入后我们将根据个人技能进行分工，最终成果将无偿贡献给全体同学使用。

## 5. 资料更新与投稿方式
管理员将会在收到投稿的一周之内进行处理。

### 📩 投稿途径
1. **邮箱投稿**：将资料发送至文末官方邮箱。
2. **GitHub 投稿**：熟悉 Git 操作的同学可通过 **Pull Requests** 直接投稿。
3. **意见建议**：如有任何建议或想法，欢迎发送 **Issues** 进行讨论。

### 🏷️ 署名说明
* **默认处理**：一般投稿默认不进行署名。
* **署名需求**：如有署名需求，请在邮件或 PR 中说明，并自行提供一份 `README.md` 文档用于说明投稿的具体内容。
* **格式要求**：署名内容不限（实名或昵称均可），但严禁含有不良信息。

## 6. 免责与合规说明
* **费用声明**：再次强调本项目**不收取任何费用**。任何商业活动或收费活动均非本项目成员承办，亦不得以本项目名义开展。
* **内容审核**：项目开展过程中严禁涉及任何不良或违规信息，项目管理者将执行严格的审核机制。
