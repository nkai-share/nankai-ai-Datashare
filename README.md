# 📚 NKAI DataShare

> **打破信息差，让复习更加简单。**

[访问资料平台](https://nkai-share.github.io/nankai-ai-Datashare/)

NKAI DataShare 是由学生自发维护的南开大学人工智能学院课程资料共享项目，希望通过持续整理真题、课件、复习笔记和学习经验，减少重复劳动与信息差，让学习资料能够跨年级持续传递。

## 项目目的

- **消除信息差**：降低复习资料的获取门槛，让同学们能够公平、方便地获得学习参考资料。
- **减负增效**：减少重复收集和整理资料所花费的时间。
- **持续传承**：按学期和课程整理资料，为后来者保留清晰的复习线索。
- **共同建设**：鼓励同学通过投稿、校对和反馈持续完善项目。

## 核心准则

1. **无偿分享**：所有资料均用于学习交流，项目不收取任何费用。
2. **严禁商业化**：不得以本项目或仓库资料进行任何形式的商业买卖。
3. **尊重贡献者**：尊重原作者和投稿者，并按投稿意愿保留合理署名。
4. **保护隐私**：不得上传包含学号、联系方式等个人隐私的信息。
5. **合规共享**：不公开受限制材料以及明显不适合传播的内容。

## 加入我们

项目需要持续更新，也欢迎新的同学参与：

- 收集和整理复习资料、课件、回忆版试题及往年真题；
- 校对课程分类、文件信息和资料内容；
- 提交使用反馈与改进建议；
- 参与项目维护、宣传和协作。

我们希望每一位参与者都具有开放、互助和尊重他人的分享精神，所有成果将继续无偿提供给同学们使用。

## 资料投稿

管理员会在收到投稿后尽快整理和处理：

1. **邮箱投稿**：发送资料至 [nkai_share@163.com](mailto:nkai_share@163.com)。
2. **GitHub 投稿**：Fork 仓库，将资料放入对应学期和课程目录后提交 Pull Request。
3. **意见建议**：通过 [GitHub Issues](https://github.com/nkai-share/nankai-ai-Datashare/issues) 反馈问题或参与讨论。

一般投稿默认不署名；如需署名，请在邮件或 Pull Request 中明确说明。署名可以使用实名或昵称，但不得包含不良信息。

## 免责与合规说明

仓库资料来自公开整理和同学投稿，仅供学习交流。课程安排、考试范围、参考答案和资料内容可能存在遗漏、错误或时效差异，请以任课教师和学校发布的信息为准。

任何商业或收费活动均非本项目成员承办，也不得以本项目名义开展。如资料涉及权利或隐私问题，请通过邮箱说明文件路径与处理诉求，维护团队会及时核查。
