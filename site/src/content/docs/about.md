# 关于 NKAI DataShare

NKAI DataShare 是由学生自发维护的课程资料共享项目，希望通过持续整理真题、课件、复习笔记和学习经验，减少重复劳动与信息差。

## 我们在做什么

- 按学期和课程整理公开学习资料；
- 提供可搜索、可筛选的静态资料平台；
- 为后来者保留清晰的课程复习线索；
- 鼓励通过 Pull Request 和邮件持续共建。

## 核心准则

1. 所有资料无偿分享，禁止商业化。
2. 尊重原作者和贡献者，按投稿意愿保留署名。
3. 不公开个人隐私、受限制材料和明显不适合传播的内容。
4. 资料仅作学习参考，不保证完整性、准确性或时效性。

## 免责声明

仓库资料来自公开整理和同学投稿，仅用于学习交流。课程安排、考试范围和答案可能发生变化，请以任课教师和学校发布的信息为准。如资料涉及权利或隐私问题，请发送邮件说明文件路径与处理诉求，维护团队会及时核查。
